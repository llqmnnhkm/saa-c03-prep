# Lab screenshots

Each lab step shows a placeholder until you add a real screenshot here.
Name the file after the step number and it shows up automatically:

```
assets/labs/<lab-id>/step-<n>.png
```

| Lab | Folder | Steps |
| --- | --- | --- |
| Host a website on EC2 | `ec2-website/` | step-1.png … step-7.png |
| Static website on S3 + CloudFront | `s3-cloudfront/` | step-1.png … step-7.png |
| Build a VPC with public and private subnets | `custom-vpc/` | step-1.png … step-7.png |
| Highly available web tier: ALB + Auto Scaling | `alb-asg/` | step-1.png … step-7.png |
| Give EC2 access to S3 with an IAM role | `iam-role-s3/` | step-1.png … step-6.png |
| Launch a resilient RDS database | `rds-multiaz/` | step-1.png … step-7.png |

The grey bar on each placeholder in the app tells you which console page the
step is about (for example *EC2 › Instances › Launch an instance › Network
settings*). Screenshot that page and save it with the matching name.

Tips:
- PNG, roughly 1200–1600 px wide, is plenty. Crop to the part that matters.
- Hide account IDs and other private details before committing — the repo is public.
- Tap a screenshot in the app to view it full screen and pinch to zoom.
